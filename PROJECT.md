# PROJECT INFO

Universal Web Components: A framework-agnostic library of native Web Components for building user interfaces. The components are designed to be reusable, customizable, and compatible with any web framework or vanilla JavaScript.

Universal Web: An evolution of the Web called a Nexus. Client-Server Web model with an evolution on Network Data Transport, Domain Name System (DNS), Web languages, Web Browsing, native AI Integration, and native cryptocurrency integration. The Nexus supports both traditional web applications, decentralized applications (dApps), and hybridization enabling a more open and user-centric web experience.
UW consists of several technologies:
- Universal Web Components: A library of native Web Components for building user interfaces.
	- Each component has native AI/Agent support for enhanced interactivity and functionality.
		- Doesn't require models to have vision support works with text-based models by providing structured data and metadata directly from the components.
- UDNS (UNS): Universal Domain Name System, a decentralized domain name system for the Nexus.
	- Domain Information System (DIS): A DNS replacement with binary domain name and record support with full UTF-8 compatibility.
		- EMOJI Domains: Support for domain names using emojis, leveraging the full range of UTF-8 characters.
	- Structured in strict CBOR.
- Universal Web Protocol: A set of protocols for secure communication, data exchange, and interoperability between web applications and services.
	- UDSP: Universal Data Transport Protocol, a protocol for efficient and secure data transfer.
- Universal Web Tools: A collection of tools and utilities for developers to build, test, and deploy web applications on the Universal Web platform.
- Viat: a native post-quantum cryptocurrency integrated into the Nexus
- Cryptography utilities: A collection of cryptographic tools and utilities for secure communication and data protection on the Universal Web platform, Browser, & Viat.
- Viat Wallet site: A web application for managing Viat cryptocurrency wallets, transactions, and interactions with the Viat network.
